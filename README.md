# Cisco Networking Portfolio

Welcome to my **Cisco Networking Portfolio**!

This repository showcases my practical networking projects, configurations, and hands-on experience using Cisco Packet Tracer.

The projects demonstrate my understanding of networking concepts, including:

- Network topology design and implementation
- VLAN configuration and inter-VLAN routing
- IP addressing and subnetting
- DHCP configuration
- Routing and switching
- Network security and access control
- LAN design and troubleshooting

### How to Explore My Projects

1. Browse the project folders in this repository.
2. Download the project files you wish to explore.
3. Open the downloaded files using your preferred network simulator (Cisco Packet Tracer).
4. Inspect the network topologies, configurations, and connectivity.

**My goal:** To continuously develop my networking skills through practical projects and document my progress in the networking field.
